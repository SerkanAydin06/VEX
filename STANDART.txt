VEX — CANONICAL PROJE STANDARDI
================================
Belge sürümü: R29 / scene-authority + canonical-lighting + shadow-contract

Bu dosya yeni level, kapı, silah, HUD, save, Bastion ve localization işleri için tek teknik referanstır.
Eski BaseTrim/süpürgelik kuralları GEÇERSİZDİR ve projeden kaldırılmıştır.


1) MODÜLER DÜNYA ÖLÇÜLERİ
-------------------------
Oda modülü       : 12 x 10 m
Net iç yükseklik : 7.00 m
Zemin kalınlığı  : 0.40 m
Tavan kalınlığı  : 0.40 m
Duvar kalınlığı  : 0.40 m
Beyaz ışık alt kat Y : 6.82 m
Beyaz ışık üst kat Y : kat tabanı + 6.82 m (VEX-03 için 14.62 m)
Beyaz ışık gölge : AÇIK

Canonical beyaz ışık profilleri (değerler KODDA değil SAHNE PREFABINDA tutulur):
- NORMAL ROOM  : res://scenes/world/ceiling_light_white_horror.tscn
  energy 2.6 / range 7.4 m / cone 18° / cone attenuation 1.6 / distance attenuation 0.35 / shadow AÇIK
- FULL / SPAWN : res://scenes/world/ceiling_light_white_fill.tscn
  energy 3.8 / range 9.2 m / cone 42° / cone attenuation 1.6 / distance attenuation 0.3 / shadow AÇIK
- LARGE VOLUME : res://scenes/world/ceiling_light_white_large.tscn
  energy 8.0 / range 20.0 m / cone 80° / cone attenuation 4.0 / distance attenuation 0.0 / shadow AÇIK

Kurallar:
- Level 1, Level 2 ve Level 3 normal odalarda NORMAL ROOM profilini kullanır.
- Spawn/özellikle aydınlatılması gereken küçük alanlarda FULL / SPAWN profili seçilir.
- LARGE VOLUME yalnız iki kat yüksekliğindeki özel hacim gibi açıkça gerekçeli alanlarda kullanılır.
- Level sahnelerinde bu profil sayılarını kopyalayan light_energy/light_range/cone override blokları tutulmaz; doğru prefab seçilir.
- room_ceiling_light.gd yalnız Inspector/prefab değerlerini child SpotLight3D üzerine uygular; profil seçmez ve level ayarlarını ezmez.
- world_piece canonical olarak gölge üretir; duvar/tavan/zemin ve kapı shadow blocker yapıları beyaz ışık sızıntısını fiziksel olarak keser.
- SHADOW CONTRACT: NORMAL ROOM, FULL / SPAWN ve LARGE VOLUME beyaz ışık profillerinde shadow AÇIK olmak zorundadır.
- Kapı durum ışıkları (kırmızı/yeşil) de shadow AÇIK kullanır. Kapalı kapıda DoorShadowBlocker yalnız gölge üreten (shadows-only) görünmez engelleyici olarak aktif olur.
- Canonical world_piece cast_shadow AÇIK'tır. Level 1/2/3 instance'ları shadow_enabled=false veya cast_shadow=false/0 ile bu standardı EZEMEZ.
- Gölge istemeyen özel dekor/efekt gerekiyorsa level instance override yapılmaz; gerekçeli AYRI prefab/material oluşturulur. Böylece level sahnesi canonical shadow standardını sessizce bozamaz.
EXIT tabela Y    : 4.85 m
Texture standard : lowercase snake_case; sürüm eki kullanılmaz
Enemy filtre     : Linear Mipmap; Fixed-Y billboard

Enemy taban Y örnekleri:
- Hellmagma  : -0.10
- Ravager    : -0.25
- Voidweaver : -0.02

4) CANONICAL KAPI STANDARDI
---------------------------
Tek referans prefab:
  res://scenes/props/door_side_slide.tscn

Ayrı Bastion kapı prefabı YOKTUR. Bütün level/hub kapıları aynı sahneyi kullanır.

Canonical kapı geometrisi:
- Sol/sağ PanelBody / collision : 0.20 x 4.48 x 2.20 m
- İki yana açılma offsetleri     : Z -2.10 / +2.10 m
- Frame jamb                     : 0.42 x 4.48 x 0.24 m
- Jamb merkezleri                : Z -2.34 / +2.34 m
- Frame header                   : 0.42 x 0.24 x 4.92 m
- Header merkez Y                : 2.36 m
- Pocket floor                   : 0.37 x 0.03 x 1.96 m
- Pocket merkezleri              : Z -3.44 / +3.44 m
- Threshold                      : 0.18 x 4.44 m plane; kapı sahnesinin içindedir

Canonical duvar açıklığı çevresi:
- Dikey yan duvar parçası : 0.40 x 7.00 x 2.54 m
- Dikey top-fill          : 0.40 x 2.28 x 4.92 m
- Yatay top-fill          : 4.92 x 2.28 x 0.40 m
- Alt kat top-fill merkez Y: 5.86 m
- Çok katlı üst seviye top-fill Y, ilgili kat tabanına göre aynı 4.48 m kapı yüksekliğini korur.

Kapı davranışları prefab çoğaltılarak değil Inspector ile ayrılır:
- automatic_open
- auto_close / auto_close_delay
- locked
- required_key / required_keys
- permanently_locked
- campaign_unlock_stage

Kapı durum ışığı:
- Anahtar/erişim isteyen kapı: KIRMIZI
- Normal kullanılabilir kapı : YEŞİL
- Işıklar kapının üstünde, mevcut level standardındaki Y hizasında kalır.

Bastion campaign kapıları:
- campaign_unlock_stage >= 0 ise kapı, GameState.campaign_stage yeterli olduğunda runtime'da açılır.
- Bu değer sahne/Inspector verisidir; bölüm scriptine kapı adı hard-code edilmez.

9) CAMPAIGN SAVE — CHECKPOINT YOK
--------------------------------
- Mid-level checkpoint YOKTUR.
- CHECKPOINTS_ENABLED = false kalır.
- Campaign persistence AÇIKTIR (CAMPAIGN_SAVE_ENABLED = true).
- Oyuncu ölünce bölüm başlangıcına döner.
- Continue, son güvenli campaign sınırından devam eder; öldüğü koordinattan devam ettirmez.

Kalıcı save noktaları:
- Bastion-7'ye varış
- görev deploy edilirken görev GİRİŞİ
- level tamamlanırken bir sonraki güvenli sahne
- Bastion'da loadout değişimi
- Bastion'da weapon upgrade kurulumu

Campaign save şunları saklayabilir:
- campaign_stage
- difficulty
- güvenli resume scene path
- kalıcı silah sahipliği/loadout
- magazine/reserve/progression state
- weapon upgrade seviyeleri
- kalıcı night-vision sahipliği gibi campaign state

Campaign save şunları SAKLAMAZ:
- oyuncu world position / rotation
- level içi key kartları
- öldürülen düşman listesi
- toplanan level pickup listesi
- bulunan level secret state'i
- kapıların level içi açık/kapalı durumu
- mid-level can/mühimmat değişimini checkpoint haline getiren world snapshot

Save version: 5.

- pistol  -> p01

15) AYARLAR / PC UX
-------------------
SettingsManager kalıcı olarak yönetir:
- language
- resolution / fullscreen / vsync
- graphics quality / render scale
- master/music/sfx
- brightness

Brightness scene-authority standardı:
- WorldEnvironment içindeki ambient_light_energy, fog_light_energy ve tonemap_exposure level/hub sahnesinin atmosfer verisidir; SettingsManager bunları değiştirmez.
- adjustment_brightness sahnedeki değer baseline kabul edilir.
- default_brightness değerinde kullanıcı çarpanı tam 1.0'dır; sahnedeki brightness birebir korunur.
- Kullanıcı brightness ayarı yalnız scene adjustment_brightness baseline değerinin üstüne göreli çarpan uygular.
- Runtime slider değişimlerinde baseline ilk sahne değerinden tutulur; üst üste apply çağrıları baseline'ı kaydırmaz.
- mouse sensitivity
- FOV
- screen shake
- head bob
- difficulty
- controller look sensitivity
- rebindable keyboard mappings

FOV aralığı: 60–110; varsayılan 78.
Key bindings user://vex_settings.cfg içindeki [keybindings] bölümünde saklanır.
Klavye rebind yalnız keyboard eventini değiştirir; gamepad bindinglerini silmez.
Temel gamepad desteği sol stick hareket, sağ stick bakış, trigger aim/fire ve standart action button eşlemelerini içerir.
